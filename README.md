
# ÉLORA Fine Dining 🍽️

A modern and elegant restaurant website built to deliver a premium digital dining experience.

## 🌐 Live Demo

🔗 https://elora-restaurant.vercel.app/

## ✨ Features

- Modern and responsive restaurant website
- Elegant hero section and restaurant story
- Featured food menu with expandable menu view
- Why Choose ÉLORA section
- Restaurant image gallery
- Customer testimonials section
- Table reservation form interface
- Contact information and opening hours
- Smooth scrolling and interactive navigation
- Scroll animations and modern UI effects
- Reusable React components
- Mobile, tablet, and desktop responsive layout

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- React Router
- Tailwind CSS
- Motion
- Vite

## 🎨 Design

- Dark navy background
- Vibrant orange accents
- Clean typography
- Modern restaurant branding
- Responsive layouts
